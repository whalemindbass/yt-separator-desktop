How it works

세 단계면 충분합니다

분리하고, 녹음하고, 내보냅니다. 순서대로 따라가면 커버가 완성됩니다.

01

분리

원곡을 보컬·드럼·베이스·기타 등 4·6스템으로 나눕니다. 지울 파트와 남길 파트를 먼저 정할 수 있습니다.

02

녹음과 믹스

원곡 영상을 보며 내 파트를 얹습니다. 저지연 모니터링과 VST 이펙트, 트랙별 볼륨으로 소리를 정리합니다.

03

내보내기

편집한 뒤 원하는 구간만 골라 저장합니다. 전체 믹스와 내 트랙만 중에서 선택해 WAV·MP3로.

Features

커버 작업에 필요한 도구

연습부터 완성까지, 데스크톱 성능으로 한자리에서.

스템 분리

4·6스템, GPU 또는 CPU로. 로컬 파일도 인터넷 없이 처리합니다.

영상 보며 녹음

원곡 영상과 맞춰진 타임라인에서 내 연주를 그대로 얹습니다.

저지연 모니터링

ASIO로 연주하는 즉시 들립니다. 밀리초 단위의 반응.

VST3 이펙트

내 플러그인을 트랙마다 체인으로. 프리셋을 저장해 다시 씁니다.

내장 튜너

정밀한 음정 검출과 A4 기준음 선택. 저음까지 안정적으로.

믹싱과 페이더

마스터·트랙 볼륨, 뮤트와 솔로, 스템 믹스까지 프로젝트에 담깁니다.

정밀 편집

트림·분할·페이드와 실행취소, BPM 감지로 그리드에 맞춥니다.

내보내기

WAV·FLAC·MP3, 품질과 구간을 골라. 전체 믹스 또는 내 트랙만.

프로젝트 저장

스템·클립·이펙트·믹스를 하나로. 저장한 그대로 다시 엽니다.
